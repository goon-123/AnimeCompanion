# Home cards — quick device check

Version 0.37.3, build 96. Only these affected Home layouts need checking.

1. **Continue watching:** look for a medium 80-point cover, two-line title and compact progress/episode information. Continue sits beside the episode label, with no separate footer. The next card should peek into the shelf on a typical phone. Tap artwork/title to open details; tap Continue to open the usual stream picker. Confirm the displayed episode agrees with the picker's selected episode. No poster badges should appear.
2. **Continue reading:** check both saved source history and MangaBaka entries if used. Covers are 72 points wide, with tighter spacing and two-line titles. Chapter/page/source information should stay readable. A saved source entry still resumes its saved place; a MangaBaka entry opens the correct series.
3. **Up next:** look for a compact rounded panel with a 64-point cover, two-line title, episode and original-broadcast time. No poster badges should appear. Tapping an item still opens that anime; See all opens Schedule.
4. **Sizing:** check larger text and iPad rotation/Split View if used. Cards should fit the pane, stack their contents when needed and avoid clipped labels or buttons. Continue's visual pill is smaller while retaining a 44-point touch area.

If something looks wrong, send the Home section, device, text-size setting and a screenshot. Broad app retesting is unnecessary. Simulator suites remain opt-in.
