# Home cards — quick device check

Version 0.37.2, build 95. Only these affected Home layouts need checking.

1. **Continue watching:** posters have no rating, DUB or airing-dot overlays. The artwork and card are larger, with the same rounded-panel style. Swipe across the shelf. Tap artwork/title to open details; tap the smaller Continue pill to open the usual stream picker. Confirm the displayed episode agrees with the picker's selected episode and watched progress is still present.
2. **Continue reading:** check both saved source history and MangaBaka reading entries if you use them. Larger covers and titles should show chapter/page/source information. A saved source entry should still resume from its saved place; a MangaBaka entry should still open the correct series.
3. **Up next:** each item has a larger cover in its own rounded panel, with episode and original-broadcast time. There should be no poster badge overlays. Tapping an item still opens that anime. See all should open Schedule.
4. **Sizing:** check larger text and iPad rotation/Split View if used. Cards should fit the pane, stack their contents when needed and avoid clipped labels or buttons. Continue's visual pill is smaller while retaining a 44-point touch area.

If something looks wrong, send the Home section, device, text-size setting and a screenshot. Broad app retesting is unnecessary. Simulator suites remain opt-in.
