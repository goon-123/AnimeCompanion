How to read this matrix

Verified offline requires named passing tests for the same APK checksum and source index across catalog, details, chapters, ordered pages and image transport. These tests use owned data; they do not establish live website availability or every optional reader branch.

Partial means some reading stages have exact-version fixture evidence. Runtime blocker means a reading or loading probe reached a missing API or interpreter decoding error. It describes this build's exercised path, not permanent source support. Unverified means more representative testing is needed.

Probe only accepted a generic empty response and does not verify the stage. Browser needed needs the native WebKit harness. Limit reached and incomplete probes need investigation. An unclassified empty-response failure remains unverified. Earlier APK evidence is never inherited by an update or another source language.

Counts include loaded source rows and one package row for each package that could not enumerate sources. Public catalog names are matched by source ID where available; unmatched instances retain their runtime index. No source is marked live verified.
